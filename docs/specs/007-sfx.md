# SPEC-007: Efectos de Sonido (SFX)

- ID: `007-sfx`
- Rama: `spec/007-sfx`
- Estado: `in-progress`
- Autor: IA
- Fecha: 2026-06-08

## 1. Contexto

El juego no tiene feedback auditivo. Las acciones (seleccionar, mover, combatir, ganar) son silenciosas.

## 2. Objetivo

Agregar sonidos procedurales (generados en código, sin archivos externos) para las acciones principales.

## 3. Alcance

### Incluido

- 7 sonidos generados programáticamente (sine waves / noise)
- Singleton `SoundManager` con AudioSource
- Llamadas en InputManager, BoardManager, GameOverUI

| Sonido     | Cuándo                         | Método de generación      |
|------------|--------------------------------|---------------------------|
| Select     | Al seleccionar ficha propia    | Tonos ascendente (0.1s)   |
| Move       | Al mover sin combate           | Ruido con fade (0.12s)    |
| Dice       | Al iniciar combate             | Ruido (0.2s)              |
| Hit        | Atacante gana combate          | Onda seno descendente (0.25s) |
| Block      | Defensor gana combate          | Onda seno aguda (0.15s)   |
| Victory    | Pantalla de victoria           | Acorde mayor (0.5s)       |
| Defeat     | Pantalla de derrota            | Onda descendente (0.5s)   |

### Excluido

- Archivos de audio externos (WAV/MP3/OGG)
- Efectos 3D / espaciales
- Mezcla por canales o volumen configurable

> La música de fondo se movió a [SPEC-011](docs/specs/011-bgm.md).

## 4. Criterios de Aceptación

- [ ] Seleccionar ficha → suena "Select"
- [ ] Mover a casilla vacía → suena "Move"
- [ ] Iniciar combate → suena "Dice"
- [ ] Atacante gana combate → suena "Hit"
- [ ] Defensor gana combate → suena "Block"
- [ ] Pantalla "BLUE WINS!" → suena "Victory"
- [ ] Pantalla "RED WINS!" → suena "Defeat"
- [ ] El proyecto compila sin errores

## 5. Diseño Técnico

### Nuevo archivo: `SoundManager.cs`

```csharp
public class SoundManager : MonoBehaviour
{
    private static SoundManager _instance;
    public static SoundManager Instance { get; }

    private AudioSource source;
    private AudioClip selectClip, moveClip, diceClip, hitClip, blockClip, victoryClip, defeatClip;

    void Awake() { /* singleton + generar clips */ }
    public void PlaySelect() { source.PlayOneShot(selectClip); }
    // ...
}
```

### Archivos modificados

- `InputManager.cs` — `SelectPiece()` → `SoundManager.Instance.PlaySelect()`
- `BoardManager.cs` — `MovePiece()` → PlayMove / PlayDice / PlayHit / PlayBlock
- `GameOverUI.cs` — `Show()` → PlayVictory / PlayDefeat

## 10. Notas

- Volumen: 0.5f por defecto para evitar saturación
- Los clips se generan una vez en Awake y se reusan
- Para WebGL, asegurar que el AudioSource tenga `spatialBlend = 0` (2D)
