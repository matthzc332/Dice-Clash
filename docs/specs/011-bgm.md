# SPEC-011: Música de Fondo (BGM)

- ID: `011-bgm`
- Rama: `spec/011-bgm`
- Estado: `in-progress`
- Autor: IA
- Fecha: 2026-06-10

## 1. Contexto

El juego tiene sonidos FX pero la música de fondo se manejaba con un playlist de 3 tracks cortos que rotaban. Se agregó un tema más largo (`medieval_horizons.mp3`) para gameplay y se descartan los otros del bucle de juego.

## 2. Objetivo

Separar la música en dos modos:
- **Gameplay**: un solo tema en loop infinito
- **Menú**: playlist de los temas cortos (cuando exista la escena)

## 3. Alcance

### Incluido

- `SoundManager.PlayGameplayMusic()` → carga `medieval_horizons` y lo reproduce en loop
- `SoundManager.PlayMenuMusic()` → playlist con crossfade de los 3 tracks cortos
- Actualizar `GameManager.Start()` para llamar a `PlayGameplayMusic()`
- Actualizar `007-sfx` para reflejar que música ya no está excluida

### Excluido

- Creación de la escena de menú (se hará en otro spec)
- Detección automática de escena (el menú llamará explícitamente a `PlayMenuMusic`)

## 4. Criterios de Aceptación

- [ ] `SoundManager.PlayGameplayMusic()` existe y reproduce `medieval_horizons` en loop
- [ ] `SoundManager.PlayMenuMusic()` existe y reproduce los 3 tracks cortos con crossfade
- [ ] `SoundManager.StopMusic()` detiene cualquier música
- [ ] `GameManager` llama a `PlayGameplayMusic` al iniciar
- [ ] El proyecto compila sin errores

## 5. Diseño Técnico

### Cambios en `SoundManager.cs`

| Antes | Después |
|-------|---------|
| `PlayMusic()` con playlist rotativo | `PlayGameplayMusic()` → loop single track |
| `musicTracks = { ... }` (3 tracks) | `gameplayTrack = "medieval_horizons"` |
| `currentTrackIndex`, `QueueNextTrack` | `menuTracks = { ... }` (3 tracks) |
| - | `PlayMenuMusic()` con el crossfade actual |

### API

```csharp
public void PlayGameplayMusic();  // loop infinito
public void PlayMenuMusic();       // playlist crossfade
public void StopMusic();           // stop (sin cambios)
```
